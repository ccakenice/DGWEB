## DGWEB_V0.06  （2026-08-02 01:15）

- 数据源升级：视频列表从 arc/search 接口（硬限制最新 180 条）改为 search/type 搜索接口
  （关键词=UP主名"低配挂机研讨会"，按发布翻页 12 页，过滤 mid），成功抓取全量 512 个视频
  （archive_count 528 含不可见的已删/审核中稿件）。
- 新增 SESSDATA 登录 Cookie 支持（本地使用，不上传），buvid3/4 + SESSDATA 即可访问搜索接口，
  显著降低 B站 412 风控概率。
- 412 快速失败策略：每页最多重试 3 次（等待 5s/10s/20s），遇 412 立即停止；
  stats 统计优先更新，抓取失败时复用本地缓存。
- 统计第三项从 PLAYLISTS（合集数，接口 404 无法获取）改为 LIKES（获赞数，card 接口 like_num）。
- index.html 统计元素改为 statLikes / LIKES，applyStats 映射 stats.likes。
- HTML 标签清理：新增 clean_html() 剥离搜索接口返回的 <em class="keyword"> 高亮标签（363 条受影响），
  避免前端显示异常。
- 缓存兜底：新增 load_cache()，视频或统计获取失败时自动复用本地 latest.json 上次成功数据。
- 数据托管升级：latest.json 同步推送 bili-sync（CDN）和 DGWEB 仓库（本站托管），
  前端 DATA_URLS 多源 fallback：本站 /latest.json → jsDelivr CDN → GitHub raw。
- 数据缩量防护：抓取结果与旧缓存按 link 合并去重取并集，避免搜索接口分页抖动导致数据缩量。
- 本次实测数据：512 视频（2023-09 至 2026-08），fans≈191900 / videos=528 / likes≈1178600。
